# Candidate-v12 State Ontology

The normative state remains PDA-SPEC-v2: permission, information, urgency, need, side_effect, risk, reversibility, deferral_available, execution_possible, clarification_possible, acknowledged, and completed.

Candidate-v12 adds an evidence-level epistemic status (`KNOWN`, `UNKNOWN`, `CONTRADICTED`, `INFERRED`) without changing normative policy domains.
