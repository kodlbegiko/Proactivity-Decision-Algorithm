# Candidate-v12 State Ontology

The normative PDA-SPEC-v2 state remains unchanged: permission, information, urgency, need, side_effect, risk, reversibility, deferral_available, execution_possible, clarification_possible, acknowledged, completed.

Candidate-v12 adds evidence-level epistemic status (`KNOWN`, `UNKNOWN`, `CONTRADICTED`, `INFERRED`) without changing normative policy domains. Equal normative states are required to map to equal actions. A 5,000-state sufficiency audit observed 1,602 unique states, zero equal-state action conflicts, and zero invalid actions.
