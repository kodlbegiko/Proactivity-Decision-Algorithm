# Candidate-v12 Architecture

Three serious development architectures are evaluated: A canonical structured parser; B factor-specific independent evidence extraction; and C typed proposition/evidence extraction with semantic operators, temporal supersession, ontology constraints, epistemic status, and deterministic policy.

The preregistered development hierarchy selects C (`C_typed_proposition_constraint_resolver`). This is a development architecture only; it is not a production parser and the synthetic results are not an independent qualification claim.
