# Data policy

## Separation

- `development/`: visible pilot scenarios; never treated as protected evidence.
- `schemas/`: machine-readable structural definitions.
- `protected/`: future protected artifacts. Do not place protected labels in public development paths.

## Current dataset status

`development/pilot_v0.jsonl` is a **synthetic pipeline/taxonomy pilot**, not validated ground truth. The corresponding annotation worksheet is intentionally blank until independent labeling occurs.

No protected set exists yet.
